// The names of SLUS_009.21, by address. This file is the register: the one place
// that says what each named symbol is called, where the name came from and what
// backs it. recipe/compile.py reads the `name = 0xADDRESS;` part; the rest of a
// row is for people. docs/naming.md has the rules in full.
//
// A function or datum with NO row here is named for its address (func_80012345,
// D_800B1234): nothing is claimed about it. A row whose name IS an address is
// here for what it says after the `//`: a note, or `was:`, a name it once had
// that was taken away because nothing backed it. A row whose name is not its
// address carries:
//
//   type:  size:   what the first split recorded
//   src:           where the name came from
//       sdk-bytes  its bytes are a member of Sony's library, in the release this
//                  program links, outside the fields the linker fills; the name
//                  is Sony's symbol
//       sdk-link   a member proven that way calls it by this name
//       sdk-later  it is part of a member proven that way, which gives it no public
//                  name; a LATER release of Sony's libraries exports the identical
//                  bytes under this name. Not what the linked release calls it:
//                  what a later one does.
//       sdk-earlier  it is part of a member proven that way, which gives it no
//                  public name; an EARLIER release exports the identical bytes
//                  under this name (psx_psyq_signatures). Not what the linked
//                  release calls it: what an earlier one did.
//       sdk-text   it is part of a member proven that way, and Sony's own text in
//                  that member names it: a string it prints begins with the name,
//                  or a message of the member names it as the function it calls
//       original   the developers' own name: the function's own assertion message
//                  begins with it, or its own debug print does and the values in
//                  the print's parentheses are the function's own arguments
//       port       Eternal Silver's name for its transcription      (none yet)
//       public-source  a function of a published source file that the developers
//                  compiled into the program: the same parameters, and the published
//                  body statement by statement. The row names the file and lists what
//                  the program's copy leaves out or replaces
//       coined     given here, by reading the C; the row says what was read
//       inherited  came with the first split or its auto-naming and has not been
//                  read since. NOT evidence of what the function does.
//   on:            the day the name, or its source, was recorded
//   was:           every name it had before, newest first. A citation by an old
//                  name is resolved here, not in a version history.
//   ev:            the evidence, to the end of the line
//
// Nothing checks this file yet (docs/naming.md, "What is not checked"). Until
// something does: a function's address is its identity, so cite it by address,
// or by name with the address beside it.
