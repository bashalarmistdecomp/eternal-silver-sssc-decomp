# Functions whose epilogue puts `addiu $sp` in the LOAD delay slot and
# leaves the RETURN slot nop  (delayfill.load_slot_epilogue).
#
# MIPS I has a load delay slot, so something must sit between `lw $ra` and
# `jr $ra`. When $ra is the epilogue's ONLY restore, the stack adjust is
# the sole candidate and the branch slot is left nop; our toolchain picks
# the other legal ordering by default.
#
# PER FUNCTION on purpose. The original compiler emitted BOTH orderings
# for locally identical code (_spu_FiDMA vs sound_noise_step: same shape,
# same 0x18 frame, opposite choice), so this can never be generalised to a
# file or an object.
#
# Every name below is MEASURED from that function's own target asm
# (by station-tools, to be released later), not inferred from a neighbour.
# Harmless where it does not apply: the swap only fires on an exact
# `lw $ra / nop / jr $ra / addiu $sp` epilogue, and `make` is the judge.
